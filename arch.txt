Document QA — Implementation Specification

Architecture

Two-process system: FastAPI backend + Streamlit frontend, communicating over HTTP.

Backend — api/app.py

POST /upload — accepts one or more files + a session UUID (multipart form). For each file: saves to temp, extracts text, removes temp file. Chunks all text, embeds all chunks, merges into one FAISS index, stores in RAM.
POST /ask — accepts session UUID + question (form). Embeds question, retrieves top-5 chunks via FAISS, sends context to LLM, returns answer.
Startup warmup — embedding model pre-loaded on server start via lifespan.
JSON structured logging to terminal and app.log.

Text Extraction — ingestion/extractor.py

PDF: PyMuPDF for text, EasyOCR for embedded images
Images: EasyOCR
Lazy-loaded OCR reader (loaded on first use)

RAG Pipeline — pipeline/

chunker.py — splits text into 500-word chunks with 50-word overlap
embedder.py — BGE-base-en-v1.5 (768-dim), lazy-loaded, normalized embeddings
retriever.py — FAISS IndexFlatIP cosine search, returns top-5 chunks

Session Storage — session/store.py

RAM dict keyed by session UUID
Stores chunks (text) + FAISS index per session
No persistence, cleared on server restart

LLM — llm/backend.py

Primary: OpenRouter (model configured via OPENROUTER_MODEL in .env)
Fallback: DistilBERT local QA model (when no API key present)
Model and key read fresh per request from env

Frontend — app.py

Streamlit
Multi-file uploader with Upload button
Spinner on upload and on ask
Session UUID generated client-side, sent with every request

Config — config.py

CHUNK_SIZE    = 500
CHUNK_OVERLAP = 50
EMBEDDING_MODEL = BAAI/bge-base-en-v1.5
TOP_K         = 5

Not implemented: Docker, rate limiting, persistence, auth, NER, Redis caching
