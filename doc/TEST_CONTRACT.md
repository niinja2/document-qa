# Document QA API — Test Contract

Base URL: `http://localhost:8000`

---

## POST /upload

**Form fields:**

| Field | Type | Description |
|---|---|---|
| `file` | file (multipart) | One file per request. Supported: `.pdf`, `.png`, `.jpg`, `.jpeg`, `.tiff`, `.bmp` |
| `session_id` | string | UUID generated by the client |

**Success response (200):**
```json
{"status": "ok"}
```

**Error responses:**

| Code | Condition |
|---|---|
| `413` | File exceeds maximum size (default 50 MB) |
| `422` | File too small, unsupported type, extraction failed, or empty text |
| `429` | Rate limit exceeded |
| `500` | Unexpected server error |

**Behavior:**

- Uploading with the same `session_id` overwrites the previous session
- Text is chunked at 350 words with 50-word overlap (configurable via env)

## POST /ask

**Form fields:**

| Field | Type | Description |
|---|---|---|
| `session_id` | string | UUID of an existing session |
| `question` | string | Natural language question |

**Success response (200):**
```json
{"answer": "..."}
```

**Error responses:**

| Code | Condition |
|---|---|
| `404` | Session not found — upload a document first |
| `422` | Missing required field |
| `429` | Rate limit exceeded |
| `500` | Missing LLM configuration (`OPENROUTER_API_KEY` or `OPENROUTER_MODEL`) |
| `502` | LLM service error or unreachable |
| `504` | LLM service timed out |

**Behavior:**

- TOP_K = 5 chunks retrieved per question (configurable via env)

**Session behavior:**

- Sessions live in RAM, cleared on server restart
- No authentication, no TTL

## Contract history

**Original contract** sent to QA tester:
- `/upload` accepted `files` (plural, multi-file)
- `chunks` typed as `list[str]`
- `retrieve()` typed as `(question, index, chunks: list[str]) -> list[str]`

**Mid-session amendments** applied during development:
- Document attribution added — chunks now carry `doc_id` (filename)
- `chunks` type changed: `list[str]` → `list[dict]` with keys `text` and `doc_id`
- `retrieve()` updated to match: `(question, index, chunks: list[dict]) -> list[dict]`
- Context sent to LLM labeled per source file: `[filename.pdf]\nchunk text`

**Multi-file reverted:**
- Multi-file upload (`files` plural) was implemented then reverted due to retrieval imbalance — large documents dominated the FAISS index, causing the retriever to ignore smaller documents entirely
- Current implementation: single file per upload (`file` singular)
- Consequence: `/upload` reads one `file` field; a request without it (for example one using the old `files` field) returns 422. Behaviour with several `file` parts in one request is not specified and not tested
- See `doc/CHANGES.md` for full reasoning

## Notes for QA

- Tests run against a **live server** at `localhost:8000` — start it before running pytest
- Rate limit tests require a **separate server run** with default limits — see `tests/TESTING.md`
- DistilBERT fallback has been **removed** — `OPENROUTER_API_KEY` and `OPENROUTER_MODEL` must both be set in `.env`
